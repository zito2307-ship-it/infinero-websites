# infinero-websites

Website-Fließband von INFINERO: alle Kundenwebsites in einem Astro-Projekt – ein Inhaltsordner pro Kunde,
gemeinsame Bausteine und Themes, automatische Prüfung, Hosting auf Cloudflare Pages.

```bash
npm install
npm run vorschau -- K-9101      # Demo „Da Rosa“ ansehen → http://localhost:4321
npm run pruefen -- K-9101       # Prüfbericht + Screenshots in pruefung/
```

Alles Weitere (Ablauf, Bausteine, Themes, Regeln): [CLAUDE.md](CLAUDE.md).
